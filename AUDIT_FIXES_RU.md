# Исправления технического аудита

Основа изменений — приложенный основной AHK и совпадающие с репозиторием UDF/common/helper. Текст аудита использован как перечень дефектов. Код сохраняет CP1251, CRLF и требование AutoHotkey 1.1.37.02 ANSI x86.

## Дополнения

- **OBS:** переключатель «Скрыть окна из захвата OBS» на странице «Интерфейс». Используется `WDA_EXCLUDEFROMCAPTURE` для окон этого процесса, с проверкой результата. Требуется Windows 10 2004+ или Windows 11. Совместимость зависит от способа захвата OBS; скрытие игры эта настройка не выполняет. При отказе API интерфейс показывает отказ.
- **Поиск:** точные ссылки на статьи, словоформы, исправление ограниченных опечаток по словарю корпуса, более высокий вес заголовка статьи, точный проход перед приблизительным. Поддерживаются `"точная фраза"` и `-исключение`. SHA-256 содержимого входит в поколение индекса; добавленный или изменённый документ обновляет индекс и кэш запросов. Недоступные документы перечисляются явно.
- **GUI:** карточки персонажа, патруля и поста; ровная сетка полей; сведения об активном профиле; единая палитра с проверкой контраста; доступные с клавиатуры кнопки вместо текстовых псевдокнопок; ограничение окна рабочей областью монитора и прокрутка на небольших экранах.

## По каждому пункту

Столбец «Изменение» описывает реализованный код. Он не означает, что интеграция с игрой проверена.

| F02 | Успех транспорта — строго `result = 1`; `-1` не считается отправкой. |
| F03 | При инвалидировании закрывается принадлежащий скрипту HANDLE, включая завершившийся процесс. Активная удалённая операция сохраняет владение. |
| F04 | Выделение модуля через `VarSetCapacity`; проверка размера результата и ограниченный повтор перечисления. |
| F05 | Ограниченное ожидание потока, опрос завершения, сохранение памяти и HANDLE до завершения; неопределённый результат не повторяется клавиатурой. |
| F06 | `FlushInstructionCache`, окончание x86 ThreadProc через `RET 4`, проверка аварийного exit code. ABI игровых функций требует отдельной проверки. |

| F12 | Ограничение превью; ротация собственных логов; ограничение новых резервных копий; сохранение размеров при завершении изменения окна. |

| F16 | Проверка активного окна и поколения ввода; единое владение вводом; условное восстановление Clipboard; `finally`; Mock не отправляет физические клавиши. |
| F17 | Дочерние проверки запускаются с `/f`; старый отчёт удаляется; отслеживаются процесс и код завершения. |
| F18 | Проверенные INI-записи, staging в том же каталоге, flush, резервная копия и атомарная замена. Новая неизвестная схема открывается только для чтения. |

| F20 | Текстовый кодек с версией на отдельный INI-ключ; точное хранение пробелов, кавычек, переводов строк и литералов маркеров. Старый кодек читается. |

## Проверки и оставшиеся ограничения

В Linux установлены проверенный официальный AutoHotkey 1.1.37.02 и Wine в отдельном каталоге `/workspace/.ahk-cloud`, без замены системных пакетов. Проверка загрузки исходников `/iLib` прошла на Unicode x64. Поведенческие проверки выполнялись в отдельной копии с отключённым **только в этой копии** ограничением архитектуры: 71 проверка, 0 ошибок, 2 пропущенные группы интеграции. Поставляемый основной файл сохраняет требование ANSI x86.

**Windows ANSI x86, игровые адреса и ABI, стресс удалённых потоков, реальные DPI/GUI, capture OBS и созданные файлы скриншотов здесь не проверены.** Нативный A32 не запускается в доступной Linux-среде; дополнительная попытка с проверенным пакетом QEMU запустила 32-битный Wine, но не загрузила официальный A32 executable. GUI исходной и изменённой версии под U64/Wine аварийно завершался при создании многострочных полей; эти запуски не считаются успешной проверкой интерфейса.

Без проверенного эталона `azmp.dll` доступ по игровым смещениям отклоняется. Один лишь вычисленный хеш не подтверждает правильность смещений/ABI: нужен соответствующий проверенный билд. Если состояние чата невозможно безопасно прочитать, клавиатурная отправка также отказывается продолжать. При выходе с ещё исполняющимся удалённым потоком его рабочая память намеренно не освобождается; единственная такая область остаётся до завершения целевого процесса.

Для проверки в Windows запустите `tests\run_windows.cmd "C:\путь\AutoHotkeyA32.exe"`. Отчёт создаётся как `audit_selftest_report.txt`; код выхода ненулевой при провале. Затем вручную проверьте настройки и переключение страниц при 100/125/150% DPI, смену профиля/StopAll во время сценария, реальный захват OBS при включении/выключении настройки и действия на проверенном билде игры.

Старые проверки карт требуют необязательных изображений из `assets/law_maps`: в исходном репозитории их нет. Этот патч не создаёт поддельные карты и не объявляет такие проверки пройденными.
