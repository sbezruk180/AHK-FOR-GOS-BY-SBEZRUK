# AHK FOR GOS 1.1 — приложение, установка и удаление

Единый публичный релиз 1.1 объединяет приложение, AHK-исходники с зависимостями, графический установщик и отдельный унинсталлер. Включены последние исправления ранее распространявшегося установщика с внутренним номером 1.2; по запросу автора все текущие компоненты имеют публичный номер 1.1.


## Рабочие инструменты: палитра, карточки, обучение и GPS

- Личный ввод Alt+T дополнен палитрой действий: названия, близкие фразы, точные TXT и алиасы, подсказки, выбор стрелками и предпросмотр. Точные `!бинды` по-прежнему принимаются пробелом; фразы с пробелами — Enter.
- Карточки происшествий хранят отдельно ID/ник, время, заметки, снимки найденных норм и относящиеся к цели фрагменты chatlog. Смена цели не затирает прежнюю запись. Есть новые дела и читаемый экспорт UTF-8.
- Журнал показывает реальные этапы очереди, отправки, конструктора и GPS. Завершённые шаги сохраняются при ошибке. Повтор разрешён только для одного безопасного точно неотправленного сообщения; игровые команды и неопределённые вызовы не повторяются.
- Старый конструктор сохранён и дополнен блоками: перетаскивание, вверх/вниз, изменение, отключение, предпросмотр и отдельный учебный запуск выбранных шагов. Изменения переносятся в прежний текстовый сценарий с сохранением комментариев.
- Учебный режим содержит собственные чат, GPS, выбор цели и проверяемые условия действий. Вход/выход отменяют фоновые операции; прежние ID и MockMode восстанавливаются. Память игры, реальные клавиши и автоматические скриншоты в нём блокируются.
- GPS настраивается для каждого профиля: число стрелок, открытие меню/поля, подтверждение, задержка и удержание клавиш. Старые профили получают прежние значения. Пробный запуск — через 3 секунды, с проверкой активного окна и отменой без повторов.
- Исправлены найденные при интеграции ошибки: глобальные переменные GUI AHK v1, потеря черновика GPS после теста, пропуск старых пользовательских функций в палитре, приоритет пользовательских TXT, журнал родительской операции, ложная маркировка отправленного шага после ошибки callback и побочные действия учебного режима.

[Подробная инструкция, устройство модулей и границы проверки](docs/desktop/WORKBENCH_RU.md).
Публичные файлы этой сборки публикуются workflow `workbench.yml` после трёх
успешных повторений в формате AHK и трёх в формате EXE на Windows ANSI x86.
Это не подтверждение работы на реальном игровом сервере или фактического OBS-захвата.

## Обновление 26 октября 2026

- Уменьшены лишние перерисовки меню: буферизация кнопок, обновление статусов только при изменении, пропуск повторной стилизации и повторной установки роли кнопки.
- Переключатель скрытия от OBS применяется сразу и сохраняется без отдельной кнопки. `Off` снимает Windows display affinity также с уже открытых приватных окон TXT; принудительное скрытие больше не обходит общий выбор.
- Экспорт автора включён как исходный профиль первого запуска: сохранены оба профиля «Основной» / «основа», выбран «Основной», тексты, бинды и настройки. Уже существующие INI не заменяются.
- Русские буквы в экспортированных клавишах преобразуются по физической раскладке: `!е` → Alt+T, `+^а` → Ctrl+Shift+F.
- Шаблон профиля встроен в EXE и добавлен в AHK-архив/установщик. На первом запуске ANSI x86 исходные байты CP1251 сохраняются без перекодирования.

## Приложение

Сохранены бинды, TXT-команды, RP-сценарии, Auto ID при наведении с F1/F2, профили, HUD, режимы чата, GPS, конструктор действий, 20 документов законодательства и поиск. F10 открывает настройки; Alt+T — окно TXT-команд, если эти клавиши не переназначены.

Для уменьшения мерцания кнопки AHK рисуются сначала в совместимом буфере, затем выводятся одним BitBlt. DC/bitmap освобождаются после каждого кадра. Неизменившиеся значения HUD больше не записываются повторно: время, профиль, ID и подписи биндов перерисовываются только при изменении текста. Фокус окон и назначение существующих действий сохранены. В обновлении 26 октября общий переключатель OBS управляет также приватным вводом.

## Установка и удаление

Нативный тёмный интерфейс, кнопки с собственной буферизованной отрисовкой, знак GOS вместо звезды. Установка унинсталлера отключается галочкой. Без него не создаются Uninstall.exe и ярлык удаления; отдельный унинсталлер может удалить приложение позже.

Три режима: все выбранные AHK/ZIP с AHK/распознанные EXE и папки; только проект с данными; проект с сохранением профилей. Полное удаление — напрямую, без корзины. **Выбранная папка удаляется со всем содержимым**, поэтому проверьте список и подтверждение. Старые EXE узнаются по метаданным и доступному встроенному коду; ZIP проверяется без распаковки. Опустевшая папка установки удаляется, профили в третьем режиме остаются.

## Совместимость и ограничения

Установщик/унинсталлер: Windows 10/11 x64. Игра и приложение: ANSI x86, совместимая CP1251. Настройки INI сохраняются; закройте старые копии перед запуском. Смещения памяти и OBS зависят от реального клиента/Windows; в облаке их совместимость с вашим сервером не подтверждена. Цифровой подписи нет. Позиция проекта в Google/Яндекс и отсутствие санкций сервера не гарантируются.

## Проверки

Релиз публикуется автоматическим workflow только после проверки упаковки, нативных установок/удалений во временных папках Windows, интерфейсов установщика/унинсталлера и desktop-smoke AHK в Unicode тестовом хосте. Это не проверка в запущенном игровом клиенте и не проверка настоящего OneDrive. Протоколы сохраняются в артефактах workflow. Исполняемое приложение отдельно проверяется на ANSI x86 запуск через runtime-info.
