# LAW

В проект включена локальная база из 20 документов для встроенного просмотра и поиска в AHK FOR GOS BY SBEZRUK.

## Состав базы

| Код | Документ |
|---|---|
| `VU` | Внутренний устав органов внутренних дел |
| `FP` | Федеральное постановление |
| `KON` | Конституция Нижегородской области |
| `FZOP` | Федеральный закон «О полиции» |
| `TER` | Федеральный закон «О территориях с ограниченным доступом» |
| `TK` | Трудовой кодекс |
| `ARG` | Административный регламент ГАИ |
| `UK` | Уголовный кодекс |
| `VV` | Федеральный конституционный закон «О вертикали власти» |
| `KOAP` | Кодекс об административных правонарушениях |
| `PDD` | Правила дорожного движения |
| `ORUZH` | Федеральный закон «Об оружии» |
| `UPK` | Уголовно-процессуальный кодекс |
| `KAS` | Кодекс административного судопроизводства |
| `FSB` | Федеральный закон «О федеральной службе безопасности» |
| `FSIN` | Федеральный закон «О федеральной службе исполнения наказаний» |
| `VS` | Федеральный закон «О военной службе» |
| `SUD` | Федеральный конституционный закон «О судебной системе и статусе судей» |
| `ORD` | Федеральный закон «Об оперативно-розыскной деятельности» |
| `GT` | Федеральный конституционный закон «О государственной тайне» |

Файлы сохранены в Windows-1251 без BOM с окончаниями строк CRLF — это формат, совместимый с требуемым AutoHotkey v1.1 ANSI 32-bit.
