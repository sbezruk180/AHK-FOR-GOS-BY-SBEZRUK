# AHK FOR GOS BY SBEZRUK

Самостоятельное Windows-приложение для биндов, RP-действий, Auto ID, докладов и законодательства в Amazing Online. Версия приложения 1.0, совместимая INI-схема 14.

**Запуск:** `release\AHK_FOR_GOS.exe`. AutoHotkey, Python, .NET и исходные скрипты для запуска не нужны. Для новой установки настройки сохраняются в `%APPDATA%\AHK FOR GOS`; прежние INI рядом с EXE продолжают использоваться. Закройте старую AHK-копию перед запуском EXE.

## Ввод команд и работа с игрой

Alt+T или `!бинд` открывает отдельный ввод TXT-команд. На странице «TXT-команды» выбирается прежний игровой чат или окно AHK. GPS и клавиши меню отправляются последовательно с удержанием; полноэкранные окна открываются без активации. [Настройка и проверки](docs/desktop/INPUT_FIXES_RU.md).

## Функции

- Настраиваемые горячие клавиши и текстовые `!триггеры` с завершением пробелом, каталог биндов, отдельные GUI и конструктор пользовательских сценариев.
- Auto ID при наведении с ПКМ: опрос 30 мс, исходная компактная плашка, F1 — принять, F2 — отказаться. Другая цель заменяет предложение без ожидания ответа. Код проверки CPed/PlayerInfo сохранён.
- Ввод ID через служебное окно и трёхсекундный перехват цифр без активации GUI; повторный бинд подтверждает ввод, Enter/Backspace/Esc сохраняют свои действия.
- Чат: «Авто», «Память», «Вставка», «Печать всего» и «Печать фракции». Настройка интервала символов отделена от пауз действий/RP. Список фракционных команд редактируется, включая `/frac`, `/cuff`, `/deject`, `/mdc`, `/chase`.
- RP-последовательности, очередь с ограничениями/отменой, планировщик, автопатруль/автопост, построение, служебные таймеры, транспортные действия и контекстные мастера.
- Профили, роли и звания, маршруты, шаблоны, темы, импорт/экспорт INI и атомарное сохранение без удаления неизвестных ключей.
- HUD, ID-overlay, список биндов, 13 страниц настроек, служебные окна и диагностика. Отчёты открываются внутри приложения.
- 20 встроенных документов LAW, просмотр с измеряемой пагинацией, поиск статей/частей, словоформы, ограниченные опечатки, кавычки и `-исключения`.
- Chatlog, распознавание событий, доказательства/скриншоты и сохранённые проверки фокуса, чата, расстояния, ID и владения вводом.
- Общая тема и переключатель исключения собственных окон из поддерживаемого захвата OBS. Реальный захват зависит от Windows/метода OBS и проверяется в клиенте.

Игровые команды и RP отправляются в игровой чат; служебные данные/ввод/отчёты — в собственные окна. Текстовые триггеры распознаются в активном процессе игры, включая его другие текстовые поля; транспорт отдельно проверяет разрешённый контекст действия.

Проект рассчитан на 32-битный Amazing/`gta_sa.exe`, совместимый `azmp.dll` и русский ANSI CP1251. Упаковка не делает смещения клиента универсальными. Совместимость конкретного билда игры и реальный OBS в облаке не объявлены подтверждёнными.

## Исправления TXT-ввода — 19.10.2026

Режим **«Чат + окно AHK»** в настройках TXT-команд разрешает команды в игровом чате и личном окне. **«Только окно AHK»** оставляет личный ввод. Существующий выбор в INI сохраняется. Если клавиша потеряна: **«Восстановить Alt+T» → «Сохранить»**.

- **Alt+T**, `!бинд` или `!bind` открывают личное окно в обоих режимах, включая редактирование биндов. При удержании Alt окно появляется сразу и ждёт отпускания клавиши.
- Команды поддерживают английские имена и неверную раскладку: `!пдп` / `!pdp` / `!glg`, `!сву` / `!svu` / `!cde`, `!сигналы` / `!signals` / `!cbuyfks`. В игровом чате завершайте команду пробелом.
- Явно заданный пользователем TXT имеет приоритет над дополнительным английским именем. После переназначения старый вариант раскладки снимается; отключённая команда не получает алиасов.

[Причины, исправления и пределы проверки](docs/desktop/TEXT_INPUT_REPAIR_RU.md).

## Новое: законы и RP-памятки — 19.10.2026

База laws заменена присланной редакцией: 7 документов изменились, остальные 13 совпадают. ФЗ о ФСБ в присланном файле **неполон: отсутствуют статьи 24–31**. Новые изображения территорий не приложены; локальные карты явно помечены как архивные.

- `!сигналы` — ВГП **03:30 / 07:30 / 15:30 / 19:30**, RP-капты **10:00 / 19:00**; интервалы сбора за **20–30 минут**, только для спецподразделений.
- `!пдп` — 8 игровых RP-сценариев помощи, включая передачу медикам.
- `!сву` — игровые RP-сценарии обнаружения предмета, оцепления, взаимодействия специалистов и завершения сцены.

В игровом чате TXT-команда срабатывает на пробел; в режиме «Только окно AHK» она вводится через личное окно. **PgUp/PgDn** листают страницы, **Esc** закрывает памятку. Клавиши и TXT меняются в настройках, сохраняются отдельно в каждом профиле. Памятки используют оформление, пассивный показ и настройки защиты захвата окна законки; ничего не отправляют в чат.

EXE распознаёт семь прежних комплектных TXT по SHA-256 и использует обновлённые встроенные документы, сохраняя файлы на диске. Собственные изменённые TXT остаются приоритетными. [Подробности обновления](docs/desktop/LAW_GUIDES_UPDATE_RU.md).

## Установка и обновление

Можно запускать EXE прямо из `release` или перенести один EXE в свою папку. Для portable-режима используйте `--portable`/файл `portable.mode`. Явная папка: `AHK_FOR_GOS.exe --data-dir "C:\AHK-GOS-data"`.

`install.cmd` необязательно устанавливает EXE и ярлыки в профиль пользователя. AutoHotkey и ассоциации `.ahk` установщик не меняет. Обновление заменяет EXE; пользовательские INI не перезаписываются. `uninstall.cmd` сохраняет настройки и логи.

Если старые настройки находятся рядом с EXE, используется прежняя папка. При недоступности её записи файлы копируются в папку пользователя без перезаписи существующего назначения. Подробности при конфликте/переносе: [BUILD_AND_RUN_RU.md](docs/desktop/BUILD_AND_RUN_RU.md).

## Сборка из исходников

```powershell
.\build.ps1
python tools\verify_exe.py dist\AHK_FOR_GOS.exe
```

Для сборки нужен Python 3.10+, стандартный WinAPI и официальный архив AHK 1.1.37.02. Архив загружается автоматически и проверяется по закреплённым SHA-256. Получается один `dist\AHK_FOR_GOS.exe`. Сторонних Python-пакетов, Visual Studio и отдельного AHK при запуске продукта не требуется.

Сохранён исходный режим разработки: весь проект + `run.cmd "C:\tools\AutoHotkeyA32.exe"`. Для него по-прежнему нужен AutoHotkey 1.1.37.02 ANSI x86 с CP1251; Unicode/x64 используется только в явно отмеченных облачных тестах.

## Структура

```text
release/                           готовый ANSI x86 EXE, SHA-256, build manifest
AHK_FOR_GOS_BY_SBEZRUK.ahk         точка входа
app/                               ядро, действия, чат, профили, UI, события
common.ahk, UDF.ahk                 процесс/память/WinAPI/AZMP
helper.ahk                         единственная реализация LAW/поиска/карт
chat_typing.ahk, id_capture.ahk     ввод
runtime_support.ahk                общие контракты, защита захвата, layout
service_ui.ahk, ui_style.ahk        служебные окна и единая тема
tests/                             встроенные регрессии и desktop smoke
laws/                              исходники 20 встраиваемых документов
tools/, build.ps1                  сборка, граф, проверка PE/миграции
third_party/                       лицензия и полный исходник runtime
docs/desktop/                      анализ, архитектура, проверки и инструкции
```

`helper.ahk` больше не генерируется из основного файла. Он включается один раз. Совместимая команда `python tools/sync_helper.py --check` проверяет этот контракт. Подключаемые тесты встраиваются для CLI-диагностики и не запускаются при обычной работе.

## Проверки

`tests\run_windows.cmd` выполняет регрессии готового EXE с временной папкой данных. `--runtime-info`, `--audit-selftest`, `--diagnostics`, `--selftest`, `--desktop-smoke` описаны в инструкции. Smoke-режим требует отдельную временную папку и не тестирует реальную GTA.

Полная таблица 1 284 исходных функций находится в [FUNCTION_MAPPING.csv](docs/desktop/FUNCTION_MAPPING.csv), исходные и текущие отпечатки — в `migration_inventory.json`. Сохранение тела функции отдельно от проверки её игрового действия: оба статуса указаны честно.
