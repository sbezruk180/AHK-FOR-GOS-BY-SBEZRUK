## О проекте

**AHK FOR GOS BY SBEZRUK, версия 1.0** - мой публичный AHK-помощник для игры на Amazing Online и работы в государственных организациях.

Скрипт собирает в одном месте большое количество рутинных действий: бинды, RP-последовательности, работу с ID игрока, доклады, служебные действия, документы, поиск по законодательству и дополнительные инструменты.

Проект сделан для **amazing.**

**законодательство взято с форума amazing sky.**

Проект не является официальным продуктом Amazing Online, Amazing Games или администрации проекта.

## Возможности

- Бинды и текстовые триггеры для часто используемых действий.
- Auto ID: определение ID игрока, ручной ввод, подтверждение цели, сброс и диагностика.
- Игровой HUD и отдельная ID-плашка.
- RP-сценарии для представления, погони, задержания, наручников, посадки в транспорт, досмотра, удостоверения и других действий.
- Служебные доклады, включая SOS, ДТП, вызовы и другие сценарии.
- Патруль, пост, автопатруль и автопост.
- Действия с транспортом: колонна, эвакуация, осмотр и поиск транспорта.
- Процессуальные действия: розыск, арест, штраф, протокол, права и служебные действия.
- Быстрый доступ к документам и встроенный поиск по локальной базе законодательства.
- Профили, INI-настройки и темы интерфейса.
- Конструктор пользовательских функций и последовательностей.
- Диагностика памяти, Auto ID, поиска законов и других внутренних модулей.

Часть функций работает через данные `gta_sa.exe` и `azmp.dll`, поэтому скрипт рассчитан конкретно на совместимую версию клиента Amazing Online.

## Установка

### Автоматически

1. Скачайте `install.cmd` из репозитория.
2. Запустите его обычным двойным кликом.
3. Установщик скачает официальный **AutoHotkey 1.1.37.02**, проверит SHA-256 и установит ANSI 32-bit runtime.
4. Установщик зарегистрирует этот AutoHotkey как обработчик `.ahk` для текущего пользователя.
5. Затем он скачает свежую версию **AHK FOR GOS BY SBEZRUK** из GitHub.
6. На рабочем столе и в меню «Пуск» появится ярлык **AHK FOR GOS BY SBEZRUK**.

Повторный запуск установщика обновляет файлы проекта поверх существующей установки и не удаляет пользовательские INI-файлы.

> Скрипту нужен именно **AutoHotkey v1.1 ANSI 32-bit**. AHK v2, Unicode-сборка и 64-bit сборка для основного скрипта не подходят.

### Ручной запуск

Минимально рядом должны находиться:

```text
AHK_FOR_GOS_BY_SBEZRUK.ahk
UDF.ahk
common.ahk
```

Запускайте `AHK_FOR_GOS_BY_SBEZRUK.ahk` через AutoHotkey v1.1 ANSI 32-bit.

`helper.ahk` оставлен отдельно для удобства дальнейшей доработки. Актуальная версия части helper-функций уже встроена в основной файл.

## Куда вставлять LAW

Локальная база законов находится здесь:

```text
AHK-FOR-GOS-BY-SBEZRUK/
└─ laws/
```

В папку `laws` нужно положить текстовые `.txt`-файлы. Код уже ожидает следующие имена:

```text
VU.txt
FP.txt
KON.txt
FZOP.txt
TER.txt
TK.txt
ARG.txt
UK.txt
VV.txt
KOAP.txt
PDD.txt
ORUZH.txt
UPK.txt
KAS.txt
FSB.txt
FSIN.txt
VS.txt
SUD.txt
ORD.txt
GT.txt
```

То есть когда LAW будет готов, просто вставляйте эти файлы в папку **`laws`** рядом с основным AHK. После установки программы это будет примерно:

```text
%LOCALAPPDATA%\Programs\AHK-FOR-GOS-BY-SBEZRUK\laws\
```

Если позже добавятся локальные изображения территорий, они кладутся в:

```text
assets\law_maps\
```
