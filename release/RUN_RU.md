Запустите AHK_FOR_GOS.exe. AutoHotkey и Python для запуска не нужны.

Закройте старую AHK-копию. Существующие INI рядом с EXE сохраняются; для новой установки данные находятся в %APPDATA%\AHK FOR GOS. Обновляется только EXE.

Сборка — ANSI x86 для Windows 10/11 и русской системной ANSI-кодовой страницы 1251. Игровой клиент/azmp.dll не входит в EXE. Реальная совместимость с конкретным клиентом и OBS проверяется отдельно.

Подробные инструкции, ограничения и результаты проверок: ../docs/desktop/BUILD_AND_RUN_RU.md и ../docs/desktop/TEST_RESULTS_RU.md.

Полный исходник приложения, лицензии и соответствующий исходник встроенного runtime находятся в этом же репозитории. Лицензии из одного EXE: --export-licenses.
