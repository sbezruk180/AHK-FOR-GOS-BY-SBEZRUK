# Уточнённое задание GOS 2

Самостоятельное Windows-приложение C# с выбранными функциями AHK FOR GOS, без встроенного интерпретатора. Приоритет: предсказуемость, быстрые действия, понятный статус, читаемые пассивные окна поверх игры, затем декоративное оформление. Старая версия и её данные остаются отдельно.

Обязательные сценарии: выбрать цель при наведении и F1/F2, выполнить выбранную команду, прочитать права, создать последовательность, найти норму, настроить ввод и видеть игроков рядом. Простое меню из пяти разделов: действия, конструктор, законы, настройки, сведения.

Ввод: физические scan-code со случайной скоростью, физические клавиши пользователя как разрешение следующего символа, либо память. Паузы последовательностей отделены от скорости печати. Представление/остановка/права принудительно используют память. Остановка ограничивается собственным 30-секундным интервалом после начала реального вызова; не блокирует другие действия.

Состояния: только одна последовательность, отмена без накопительной очереди, снимок настроек на выполнение, смена цели отменяет контекст. Не повторять неизвестный результат. При ошибке показать полезную причину; не писать «успешно отправлено серверу» по локальному вызову.

Интерфейс: единая тема и типографика, минимум служебных терминов, явные сохранить/отменить, защита несохранённого сценария, предсказуемый Esc, отсутствие захвата фокуса у игры. Настройки и сценарии сохраняются атомарно, импорт INI выполняется через черновик и сохраняет оригинал.

Производительность: ограниченные журналы/буферы, чтение playerpool снимком, fast-path Auto ID с перепроверкой, список окружающих обновляется отдельно от частоты прицела. Перерисовывать только изменённые данные. Не хранить write-handle игры во время обычного read-only HUD.

Приёмка: чистая сборка, реальные Core-регрессии, native Windows x86 UI/клавиатура/ABI, визуальный просмотр снимков. Отдельная клиентская проверка настоящей GTA/Amazing, fullscreen и OBS. Эксклюзивный DirectX, если внешние окна не видны, остаётся ограничением: не подменять его успешным desktop-тестом.
