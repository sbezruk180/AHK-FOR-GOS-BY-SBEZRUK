# Отчёт GOS 2.0.0-preview.1

Новая версия создана отдельно в `versions/2.0-csharp`, ветка `v2-csharp-preview`. Стабильная AHK 1.1, её релиз и исходные модули не заменены. Сборка — C# / .NET 10 LTS / WinForms, самостоятельный x86 EXE со встроенной средой. AutoHotkey не запускается и не устанавливается.

## Практический результат

- Меню из пяти разделов: действия, конструктор, законы, настройки, сведения.
- Три режима: случайная физическая печать, физическая клавиша пользователя как разрешение следующего символа, память. Настройка диапазона символов/сек. и независимых пауз между сообщениями.
- Представление, остановка и права принудительно используют память. Остановка имеет собственный интервал 30 секунд после начала вызова; прочие действия этот интервал не ждут.
- Перенесены chase, chase с выбранным ID, deject/dejected, cuff, incar с RP, SOS с исходной последовательностью меню, права в чат и в отдельном окне.
- Auto ID: ПКМ, точное соответствие указателя CPed и playerpool, F1/F2. Новая цель заменяет предложение без ожидания ответа на старую.
- Chatlog: предложение ID по собственным событиям преследования, реанимации, оглушения и поиска местоположения. Чужая цитата серверного сообщения не считается своим событием. Автоматическая отправка команд по произвольному chatlog не выполняется.
- HUD и отдельный список окружающих: количество загруженных игроков, ID, ник, расстояние. Радиус 1–300, обновление 200–5000 мс; на экране до 12 ближайших строк, счётчик включает весь найденный список.
- Все 20 исходных корпусов законов встроены без изменения текста. Названия ВУ/вертикали власти сверены с оригинальным каталогом.
- Конструктор: сообщения, паузы, уведомления и разрешённые клавиши меню, предпросмотр, редактирование, порядок, удаление, сохранение, запуск, защита несохранённого черновика. Есть поиск пользовательских сценариев в окне команд.
- Явные «Сохранить / Отменить изменения», атомарный JSON, резервная копия, импорт выбранного старого профиля без изменения INI, отдельная папка пользовательских данных.
- Единая политика OBS On/Off во всех собственных окнах; пассивные игровые окна без активации.

## Что проверено и исправлено по результатам работы

1. Исправлена потеря быстрых нажатий в клавишном режиме: ограниченный буфер только для текущей строки; удержание клавиши не создаёт лишних символов; события SendInput не разрешают сами себя.
2. Реальные клавиши не смешиваются со случайно печатаемой командой. Перехват клавишного режима включается до подготовки чата, чтобы ранние нажатия не попали в него неизменёнными.
3. Pause/Esc прерывают ввод; Ctrl/Alt/Win отменяют его. Escape для очистки не нажимается вместе с удержанным модификатором, чтобы не открыть Пуск и не переключить окно.
4. Кулдаун остановки начинается после запуска реального вызова, а не при отказе из-за открытого чата или подготовки памяти.
5. Сохранение настроек/импорт/сценарии проходят через черновик: ошибка не выдаётся за успешное сохранение и не оставляет частично применённые значения.
6. Смена цели и потеря игрового фокуса отменяют дальнейшие шаги. Перед отправкой проверяется, что выбранный игрок не изменился. Токен отмены проверяется также непосредственно перед запуском удалённого потока.
7. Сохранена корректная x86-очистка стека и независимый маркер нормального возврата. Неизвестный результат не повторяется; память работающего потока не освобождается под кодом.
8. Восстанавливается исходная раскладка только у того же окна. CapsLock учитывается при физической печати. Неподдерживаемые символы вызывают понятный отказ.
9. Устранён вызов смены стиля окна каждые 35 мс. Политика применяется при изменении параметров; HUD и список окружающих перерисовываются по изменениям данных.
10. После просмотра реальных Windows-снимков убраны горизонтальная прокрутка и обрезание подсказок; уменьшены карточки, сделана тёмная шапка с перетаскиванием и изменением размера. Отсутствие горизонтальной прокрутки проверяется на всех пяти страницах.
11. Сохранение/отмена настроек находятся в постоянной верхней панели. Палитра принимает ввод на рабочем столе и остаётся пассивной в игре. F10/Alt+T доступны также при открытом меню.
12. Публичная папка исходников стала самодостаточной: включает снимок законов, тестовый INI, лицензию и сборочные скрипты; прежняя AHK-папка для сборки не нужна.

## Что остаётся проверить на компьютере с игрой

1. Запуск без AutoHotkey/.NET, повторный запуск, выход через трей, сохранение и повторная загрузка настроек.
2. Меню F10, Alt+T, ввод в поля и чтение законов в полноэкранном режиме без рамки. Затем отдельно эксклюзивный режим и факт сохранения фокуса.
3. Auto ID при ПКМ: разные игроки подряд, F1/F2, ID 0, уход игрока и его переподключение. Неверная схема/SHA должна давать отказ, а не случайный ID.
4. Все десять записей каталога, особенно память представления/прав, оба chase, SOS Down/Enter, incar и 30-секундный интервал остановки при возможности других действий.
5. Печать русского/английского текста, смена раскладки/CapsLock, диапазон скорости, быстрые физические нажатия, удержание клавиши, Pause/Esc, Alt+Tab и Ctrl.
6. Chatlog при реанимации/преследовании, собственный ник, отсутствие срабатывания на чужую цитату.
7. Список окружающих: сравнить ID/дистанцию с наблюдаемыми игроками; сменить радиус, выключить/включить, проверить исчезновение вне игры.
8. OBS: каждый используемый источник отдельно, On и Off, HUD/команды/права/список окружающих; проверить полученную запись.
9. Длительный сеанс с измерением CPU/памяти и несколькими DPI/мониторами. Снижение ресурсов относительно AHK не заявляется без таких замеров.

## Существенные ограничения preview

Новый C#-проект содержит выбранный набор, а не все 93 действия AHK. Маски из 3D-меток, старый GPS, прежние карточки/журнал, карты и остальные сценарии старой версии не объявляются перенесёнными.

Для игры остаётся исходная схема адресов AZMP. Указание ожидаемого SHA делает проверку строгой, но структурное совпадение без него не доказывает совместимость клиента. При неизвестном результате удалённого вызова приложение не делает автоматический повтор.

**Рабочая архитектура внешнего интерфейса — DWM/полноэкранный режим без рамки. Видимость поверх настоящего эксклюзивного DirectX fullscreen не гарантируется.** Такое требование нельзя честно считать закрытым только успешным native Windows-тестом.

EXE включает .NET, поэтому размер существенно больше AHK-сборки. Отдельного установщика для новой версии пока нет; EXE переносимый. Подпись издателя отсутствует. Тексты законов сохранены из прежнего комплекта, а не подтверждены как сегодняшняя редакция сервера.
