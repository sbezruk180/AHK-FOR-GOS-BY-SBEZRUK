# Shared implementation contract
New isolated application; no AHK embedding/interpreter. Namespace Gos.Core / Gos.Windows.
.NET 10 LTS; Core net10.0; Windows net10.0-windows WinForms x86, EnableWindowsTargeting. No external UI packages.

Core owns these public types (mutable config classes with JSON serialization):
SendMode { RandomTyping, KeyAssisted, Memory }
AppSettings: string Name="Лукашенко", Rank="лейтенант полиции", Department="ГАИ", ChatLogPath="", ExpectedModuleHash=""; SendMode SendMode=RandomTyping; int MinCps=40,MaxCps=90,LineDelayMs=900; bool HideFromCapture=true,AutoId=true,AutoRevive=true,AutoChase=true,HudVisible=true; Dictionary<string,string> Hotkeys; List<Scenario> Scenarios. Settings Normalize() mutates and validates. Stop interval fixed >=30s. Default hotkeys only F10 menu, Alt+T palette, F1/F2 offer, Pause cancel; per-action keys user-defined.
TargetSnapshot record(int Id,string Name,uint Ped=0).
ActionDefinition record(string Key,string Name,string Description,bool RequiresTarget,bool ForceMemory,string[] Lines,string[] Aliases).
Scenario mutable class string Id,Name; List<ScenarioStep> Steps. ScenarioStep: string Kind="send",Text=""; int DelayMs=0. kinds send,wait,notice; validation rejects unknown kinds/unbounded delays. Builder uses structured steps, supports reorder/add/remove/save/preview/run. Template placeholders {id},{name},{rank},{department}.
ActionCatalog static All, Find(string query); Template.Expand(string,AppSettings,TargetSnapshot?). Preserved actions keys intro,chase,chase-id,deject,cuff,incar,stop,sos,rights,rights-gui. ForceMemory true intro/stop/rights. 'rights-gui' opens reference only, never sends.
ProfileStore(dataDir) Load(), Save(AppSettings), TryImportLegacy(string iniPath,AppSettings settings) bool; atomic JSON write, no overwriting legacy INI. Migration explicit UI selection. Legacy source bytes cp1251.
LawLibrary embedded law resources; public IReadOnlyList<LawDocument> Documents; Search(string) returns IReadOnlyList<LawHit>; LawDocument record(string Key,string Name,string Text); LawHit record(string Document,string Text). Constructor default loads embedded 20 sources. Rights text ActionCatalog rights lines.
AutomationRunner(IMessageTransport transport) has bool IsBusy, event Action<string>? StatusChanged; Task RunAsync(IEnumerable<ScenarioStep>,AppSettings,TargetSnapshot?,bool forceMemory=false); Cancel(); cancellation token epochs, rejects concurrent runs rather than queue; errors no retry. IMessageTransport.SendAsync(string,SendMode,AppSettings,CancellationToken):Task; throws on rejection or unknown; transport checks focus each char/memory.

Windows bridge agent owns Native.cs, GameMemory.cs, KeyboardHook.cs only:
GameMemory : IDisposable with public bool IsActive {get;}, string Status {get;}, string ExpectedHash {get;set;}; public TargetSnapshot? ReadAimTarget(); public void SendChat(string text); public void Refresh(); actual original x86 offsets. Refresh rate capped internally; revalidate foreground PID, module identity, PE32/ranges before remote calls. WaitForSingleObject with bounded wait; unknown thread retains allocations until thread signaled, never retry. ExpectedHash optional; when set strict hash check. Always bounds/PE validation.
KeyboardHook : IDisposable, installs low-level keyboard hook; event Func<KeyStroke,bool>? KeyInput; public readonly record struct KeyStroke(int VirtualKey,bool Down,bool Injected,bool Repeat); ignore injected events in subscribers; tracks repeats. KeyboardHook.TypeCharacter(char), PressKey(int), IsKeyDown(int), static methods. Unicode SendInput for Cyrillic plus physical fallback explicitly documented. Hook installed on UI thread and message loop; catch exceptions in callback. Native methods public where used: SetWindowDisplayAffinity, GetWindowDisplayAffinity, GetForegroundWindow, GetWindowThreadProcessId, GetAsyncKeyState. P/Invoke wrappers can have friendly names as long as bridgepublic API matches.

UI agent owns Theme.cs, ShellForm.cs, OverlayForms.cs only. Namespace Gos.Windows.
IAppController interface authored by parent: AppSettings Settings; string Status; TargetSnapshot? Target,Candidate; bool IsGameActive; LawLibrary Laws; event Action? Changed; Task RunAsync(string key); Task RunScenarioAsync(Scenario); void Cancel(); void AcceptTarget(); void RejectTarget(); void SaveSettings(); void Notify(string text); void ImportLegacy(string path).
ShellForm(IAppController controller), public ShowPassive(), Hide(); bool IsInputOpen; bool HandleKey(KeyStroke) returns handled for passive text entry. UI can offer standard desktop active editing; when game active ShowWithoutActivation / WS_EX_NOACTIVATE, requires passive key route to selected editable field, avoid losing focus. Implement all pages actions/builder/laws/settings with real actions. Fullscreen exclusive cannot be guaranteed by external topmost windows; borderless/DWM supported route, document clearly.
HudForm(IAppController controller), public RefreshState(); also OBS applies every actual form via WindowPolicy.Apply(Form,bool, bool passive) authored UI. CommandForm(IAppController), public Open(), bool HandleKey(KeyStroke), bool IsOpen, CloseInput(). Render passive text and filtered action results with up/down/enter/esc; no editable focus-stealing controls needed for palette.

Parent owns Program.cs, AppController.cs, ChatTransport.cs, ChatLogWatcher.cs, IAppController.cs, build/scripts/report + integration tests; all other file ownership as above. UI owns additional lightweight custom controls as needed in its own files. Communicate deviations promptly.
