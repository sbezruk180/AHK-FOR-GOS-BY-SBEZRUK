# Права в текстовом окне

Добавлено действие **«Права — текстовое окно»** в разделе **«Документы»** настроек биндов.

- Команда по умолчанию: **`!правагуи`**. Можно изменить TXT-команду и назначить клавишу в настройках.
- Окно показывает `RP_Rights` текущего профиля, с подстановкой стандартных переменных шаблона. Правка текста или смена профиля учитывается при следующем открытии, без перезапуска.
- Используется существующее пассивное законодательное окно: единая тема, измеренная пагинация, регистрация защиты от захвата. Открытие не отправляет сообщения в чат.
- **PgUp / PgDn** — страницы; **Esc** или повтор команды — закрытие. Работает возврат к последнему документу.
- При пустом тексте показана подсказка, где его заполнить. Бинд и команда сохраняются в существующем INI профиля.
- Существующее действие **«Права»**, включая `!права` и его отправку в чат, сохранено.

Собран `release/AHK_FOR_GOS.exe`, ANSI x86, SHA-256 `e41d358528c85b4cc87786b77e49722936eab87fb127363261791ef53d1e4c8f`.

Проверки находятся в `tests/reference_guides_regression.ahk`: разрешение команды, отсутствие старого текста после правки, пустой текст, настоящие окна и страницы, сохранение фокуса, регистрация защиты, закрытие, отсутствие отправок, сохранение/загрузка биндов профиля. Нативные проверки обеих форм запускает `tools/rights_gui_audit.py` / workflow **Rights text GUI native x86 checks**. Результаты будут сохранены рядом с этим документом после завершения прогона.

Реальный клиент Amazing, полноэкранный режим и кадры OBS в облаке не проверяются. Более ранний полный аудит относится к предыдущему EXE; его карта со счётчиками сохранена отдельным снимком, текущая карта функций обновлена без переноса старых счётчиков.
