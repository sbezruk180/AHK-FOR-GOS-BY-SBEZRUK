# Права в текстовом окне

Добавлено действие **«Права — текстовое окно»** в разделе **«Документы»** настроек биндов.

- Команда по умолчанию: **`!правагуи`**. Можно изменить TXT-команду и назначить клавишу в настройках.
- Окно показывает `RP_Rights` текущего профиля, с подстановкой стандартных переменных шаблона. Правка текста или смена профиля учитывается при следующем открытии, без перезапуска.
- Используется существующее пассивное законодательное окно: единая тема, измеренная пагинация, регистрация защиты от захвата. Открытие не отправляет сообщения в чат.
- **PgUp / PgDn** — страницы; **Esc** или повтор команды — закрытие. Работает возврат к последнему документу.
- При пустом тексте показана подсказка, где его заполнить. Бинд и команда сохраняются в существующем INI профиля.
- Существующее действие **«Права»**, включая `!права` и его отправку в чат, сохранено.

Собран `release/AHK_FOR_GOS.exe`, ANSI x86, SHA-256 `fbe20a816569de2906d7260e0d6e6a1de728b3485ccb4a2ff80a9bc745e4a450`.

Проверки находятся в `tests/reference_guides_regression.ahk`: разрешение команды, отсутствие старого текста после правки, пустой текст, настоящие окна и страницы, сохранение фокуса, регистрация защиты, закрытие, отсутствие отправок, сохранение/загрузка биндов профиля. Нативные проверки обеих форм запускает `tools/rights_gui_audit.py` / workflow **Rights text GUI native x86 checks**. Результаты: [Windows run 39804973960](https://github.com/sbezruk180/AHK-FOR-GOS-BY-SBEZRUK/actions/runs/39804973960), проверен commit `01851b6`. [Нативная сводка](reports/rights-gui-20261022/native-x86/summary.json): EXE — **508 регрессионных и 120 GUI-проверок, 0 ошибок**; обычный AHK — **506 регрессионных, 0 ошибок**, в GUI 118 успешных из 120, две оставшиеся проверки требуют EXE и встроенных ресурсов. Проверки самого окна прав успешны в обеих формах. На английском Windows использованы временные ANSI x86 hosts с единственным изменением PE-манифеста `activeCodePage=ru-RU`; хеши оригинала и тестовых hosts сохранены в сводке. Код приложения не инструментирован.

Дополнительно [локальный Wine/U64 стенд](reports/rights-gui-20261022/local_summary.json): 496 регрессионных и 120 GUI-проверок без ошибок, 3 интеграционные группы пропущены. Это дополнительная проверка, а не игровая ABI-совместимость.

Реальный клиент Amazing, полноэкранный режим и кадры OBS в облаке не проверяются. Более ранний полный аудит относится к предыдущему EXE; его карта со счётчиками сохранена отдельным снимком, текущая карта функций обновлена без переноса старых счётчиков.
