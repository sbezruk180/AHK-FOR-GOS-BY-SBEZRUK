# GPS из контекстной плашки и авторство

## Переход из плашки в GPS

Проблемный сценарий: после сообщения о сигнализации дома пользователь подтверждает предложение отметить дом; `/gps` открывается, но навигация останавливается из-за потери фокуса. При прямом TXT-бинде GPS работает.

В коде контекстный путь безусловно вызывал `WinActivate` по PID процесса перед GPS. Прямой TXT-бинд этот переход не выполняет. Окно, в котором появилась плашка, не сохранялось для последующего подтверждения. Исправлены именно эти различия; воспроизвести поведение конкретного Amazing-клиента без игры нельзя.

Теперь:

- Плашка запоминает HWND исходного окна игры. Номер дома сохраняется до закрытия плашки.
- Если исходная игра уже активна, повторной активации нет.
- После обычного окна ввода возврат выполняется в сохранённое окно, с проверкой его процесса; выбор произвольного окна по PID исключён.
- При переходе в постороннее приложение действие не перетягивает фокус обратно. Потеря фокуса во время GPS по-прежнему останавливает отправку клавиш.
- Повторный или запоздалый обработчик закрытой плашки не открывает GPS снова и не обращается к уничтоженному GUI.

Количество стрелок, задержки GPS, команды и профили сохранены. Защиты от отправки клавиш в постороннее окно не отключены.

## Проверки

Нативный Windows-стенд использует реальные окна, ListBox/Edit и события клавиатуры. Вместо игры подставлены принадлежащее тесту окно, флаг чата и обработчик команды памяти. Проверяются подтверждение дома, полный ввод номера, ввод через отдельное окно, выбор ID, отказ, повторное подтверждение, устаревший HWND и потеря фокуса после `/gps`. Прежние проверки прямого GPS и отмены сохранены.

[Windows-проверка 42494009021](https://github.com/sbezruk180/AHK-FOR-GOS-BY-SBEZRUK/actions/runs/42494009021) завершилась успешно. Проверенный исходный коммит до исправления истории: `b0d4f80df464b7c6f9e673ede372970138750d71`.

- AHK и EXE: по три прогона, всего 162 запуска сценариев, без неожиданных ошибок; 156 PASS и 6 ожидаемых исключений для EXE-специфичных проверок при запуске исходников.
- GPS/меню: 32 успешные проверки в каждом из шести прогонов, включая новые контекстные сценарии.
- Установка и удаление: 112 проверок; окна установщика и унинсталлера: 34 и 33. Ошибок нет.
- После каждого прогона оставшихся процессов нет.
- Публичные EXE, установщик, унинсталлер и AHK-архив скачаны и сверены по SHA-256; изменённые AHK-модули в архиве совпадают с исходниками.

[Полные отчёты](reports/context-gps-20261108/result.json), [GPS/меню](reports/context-gps-20261108/workbench-exe-1/fixture_game_menu_report.txt). ANSI x86 проверялся на Windows с тестовым ru-RU manifest; GUI-снимки отдельно выполнены Unicode x86 хостом для читаемой кириллицы на английской Windows. Работа на реальном сервере Amazing и фактическая запись OBS не проверены.

## Авторство

В описании программы автором остаётся `sbezruk180`. Причина появления `codex` в GitHub Contributors — два старых коммита; `.mailmap` не убрал их из опубликованного графика. Исправлены поля автора и коммитера этих двух записей в истории основной ветки. Удалён больше не нужный `.mailmap`. Список Contributors может обновляться с задержкой из-за кеша GitHub. Файлы и порядок изменений при исправлении метаданных сохраняются; GitHub Actions остаётся техническим ботом сборки, а не автором приложения.

Резервная версия до изменений: [backup-before-context-gps-20261108](https://github.com/sbezruk180/AHK-FOR-GOS-BY-SBEZRUK/tree/backup-before-context-gps-20261108). Дополнительно сохранён Git bundle с исходной историей перед изменением метаданных. После замены истории хеши последующих коммитов меняются; существующие локальные ветки нужно согласовать с новой `main`, прежде чем отправлять их обратно.
