# Установка и удаление 1.2 — 24.10.2026

Игровой EXE и AHK-модули не менялись. Изменены установщик и отдельный унинсталлер.

## Исправления по обращениям

1. В полном поиске появились ZIP с записями `.ahk`, включая вложенные пути и
   верхний регистр расширения. ZIP просматривается по центральному каталогу,
   без извлечения и выполнения содержимого. Поддержаны обычные ZIP/ZIP64;
   предел: 200000 записей и 32 МБ центрального каталога. Битые/нечитаемые,
   многотомные архивы и архивы с зашифрованным каталогом не распознаются.
2. Снят нижний порог размера EXE. Старые Ahk2Exe-компиляции со стандартными,
   отсутствующими или отличающимися метаданными распознаются по доступному
   встроенному скрипту и характерным признакам проекта. Файл не запускается.
   Переименование не влияет на распознавание. Упакованный/зашифрованный EXE
   с недоступным скриптом без узнаваемых метаданных не обещается распознать.
3. Полный режим использует прямые `DeleteFileW`/`RemoveDirectoryW`.
   `SHFileOperation` и `FOF_ALLOWUNDO` в реализации больше нет: корзина не
   используется. Перед удалением остаются список, ручной выбор и подтверждение
   `УДАЛИТЬ`. Выбранная папка удаляется со всеми файлами внутри.
   Сначала сверяется снимок состава и идентичности объектов; новый или
   изменившийся объект отменяет удаление этого выбранного объекта с ошибкой.
4. У кнопок собственный оконный класс, полный буфер кадра, собственные
   обработчики мыши/клавиатуры/фокуса. Стандартная тематическая рамка BUTTON
   не рисуется. Кнопки проверяются до наведения, а не после искусственного hover.
   Звезда заменена на спокойный знак GOS; иконки EXE тоже изменены.
5. AHK выбран по умолчанию и отмечен как рекомендуемый вариант. В настройках
   появилась включённая по умолчанию галочка «Установить унинсталлер».
   Снятая галочка исключает Uninstall.exe, ярлык удаления и запись в списке
   приложений Windows. Ярлык самого приложения использует иконку своего
   исполняемого файла, а не отсутствующего унинсталлера. Отдельный унинсталлер
   может удалить такую установку позже.

## Поиск

Папки дедуплицируются до проверок известных каталогов Windows. Во время
перечисления проверяются безопасные непосредственные объекты; одинаковые
цепочки родителей не открываются заново для каждого файла. Перед удалением
проверки ссылок и идентификаторов выполняются повторно.

Полный обход фиксированных дисков сохранён. Время зависит от числа файлов,
скорости диска и OneDrive. Процент ускорения не заявляется: сравнительного
замера на пользовательском диске не было. Новые проверки ZIP тоже требуют I/O.

## Проверка

[Локальные протоколы](reports/installer-20261024/): Wine/Xvfb — **107/107**
файловых проверок, GUI установки **34/34**, GUI удаления **33/33**.
Три ограничения Wine явно пропущены: два запуска ANSI x86 и NTFS-ссылка.

Проверены настоящий GitHub ZIP `6b1a595`, архив с вложенным `.AHK`, повреждённый
и посторонний ZIP, удаление выбранного ZIP с сохранением постороннего,
переименованный EXE с удалённым VERSIONINFO, его поиск и прямое удаление,
сохранение профиля, старые папки, самоудаление и независимое включение/выключение
унинсталлера при установке/обновлении. Проверены первоначальная отрисовка,
скруглённые тёмные углы без наведения, активация кнопок и новая галочка.

Нативный Windows-прогон запускается для этой же сборки; результаты будут добавлены.
На настоящем пользовательском OneDrive и всех пользовательских дисках проверка
не проводилась. Реальные профили, реестр и пользовательские ярлыки автотесты
не изменяют; LNK и установки для проверок создаются во временных папках.
