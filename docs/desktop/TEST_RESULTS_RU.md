Облачные проверки: Wine 10/Xvfb, ACP1251, явно обозначенный Unicode x64 тестовый EXE/официальный U64 runtime. Тестовый EXE не распространяется как продукт. После audit изменён только GUI-тест: копия INI теперь сохраняет исходную кодировку, включая UTF-16 на английском Windows. GUI повторён; хеши всех исходников приложения между двумя тестовыми EXE совпадают, различается только `tests/desktop_smoke.ahk`. Отпечатки записаны в summary.

В Wine нет одновременно настоящих RU/US раскладок: смешанная физическая RU/US группа явно пропускается. Строки неверной раскладки проверяются отдельно на предыдущем этапе и повторяются в Windows CI. Не следует принимать транспортные подмены за реальную отправку в игру: routing-стенд считает вызовы трёх приёмников; input/GPS-стенды подменяют игровые условия, память, наблюдение диалога и отдельные функции оформления/защиты.

## Пределы и прежние проверки

Реальный Amazing/GTA, адреса его диалогов, отправка памятью/буфером в клиент, реальный темп ввода, exclusive fullscreen и кадры OBS здесь не проверены. 10 мс удержания клавиши и игра ограничивают скорость; поле 1000 CPS не обещает 1000 фактических символов/сек. [Клиентский чек-лист](CLIENT_CHECKLIST_RU.md).

Сигналы/конструктор/GPS предыдущего этапа уже прошли Windows [run 39228439839](https://github.com/sbezruk180/AHK-FOR-GOS-BY-SBEZRUK/actions/runs/39228439839), commit `d8d03885e8b903fbd49e3ead28474fed0a83ac2e`; [отдельное подтверждение](reports/windows_ci_signals_builder_2026-10-20.json). Прежний GPS-код на новом стенде имел два отказа из 17 — поздний и неожиданный диалог; исторический протокол сохранён. Это не подтверждает единственную причину отказа клиента пользователя.

Остальные сохранённые CLI/TXT/Auto ID/законы отчёты исторические и не выдаются за новый прогон. В ФЗ о ФСБ по-прежнему нет предоставленных статей 24–31; карты остаются необязательными внешними ресурсами.

Первый Windows CI нового CPS-стенда выявил остаток символа `1` после намеренной отмены. Следующая проверка кириллицы просила не очищать текст и получала этот префикс. Добавлена очистка приёмника между независимыми тестами; сравнение точного русского текста сохранено. Исходники и EXE приложения не менялись.
