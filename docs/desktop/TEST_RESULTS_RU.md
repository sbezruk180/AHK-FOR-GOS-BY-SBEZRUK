В Win32-стендах предикат игры, состояние её чата и отправитель команды памятью — явно обозначенные подстановки. Оформление/успех privacy API в стенде ввода также подставлены; возвраты реального Capture API проверяются отдельно в desktop smoke. Это не проверка кадров OBS.

Под Wine смешанная печать RU/US явно пропущена: обе раскладки не загружаются. Для измерения цифр используется текущая HKL; нативный Windows CI использует реальные RU/US раскладки. Полный русскоязычный ANSI-прогон на hosted Windows с ACP, отличной от 1251, пропускается явно.

## Контроль до и после исправлений

- Старый commit `f22b845600e54c99c65fb27c0e01cbb226a6ca3f` с теми же новыми сценариями: **21 провал** в полном исходном audit-прогоне. Исправленный EXE: **0**. Различие общего числа проверок (441/443) связано со встроенными ресурсами и режимом исходник/EXE.
- Одинаковый стенд ввода: **29 / 4 ошибки → 29 / 0**. Состояния ввода **9 создано / 2 освобождено → 9 / 9**. Реальная утечка устранена удалением callback-таймера, а не только `Off`.
- GPS получает цифры до стирания префикса, закрывает старый чат до `/gps`, вводит номер настоящими клавишами и освобождает владельца при остановке. Не выполняет неподтверждённый повтор команды.
- Перенос старых label-обработчиков в функции потребовал обновить две статические самопроверки: теперь они проверяют и вызов функции из label, и код запуска/остановки таймера внутри функции.

## Практические ограничения

**Реальный GTA/Amazing-клиент, его ABI/адреса, серверные диалоги, физический ввод в игре, exclusive fullscreen и кадры OBS здесь не проверены.** Успех Win32-модели не объявляется подтверждённой совместимостью с игрой. При остановке GPS журнал/уведомление содержит этап, чтобы проверить реальный клиент без угадывания offsets.

Локальные картинки карт по-прежнему не предоставлены: диагностика сообщает предупреждение и сохраняет каталог/форумные действия. [Ограничения и список файлов](LIMITATIONS_RU.md).

[Клиентский чек-лист](CLIENT_CHECKLIST_RU.md) и [проверки после этого аудита](LOGIC_AUDIT_RU.md#что-проверить-в-игре) описывают оставшиеся реальные игровые сценарии. Системная кодовая страница Windows 1251 остаётся требованием исходного ANSI приложения. Пользовательские профили/INI и оформление сохранены.
