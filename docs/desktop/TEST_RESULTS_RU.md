Облачные исполняемые проверки: Wine 10/Xvfb, ACP1251. CLI запускается из явно обозначенного **Unicode x64 тестового EXE**; он не распространяется как продукт. Нативные стенды используют U64 runtime. В Wine не доступны одновременно реальные RU/US раскладки: физическая группа двух раскладок явно пропускается; ввод строк неверной раскладки проверяется отдельно. Сборка и содержимое ANSI PE32 проверяются отдельно.

В первом GUI-прогоне предпросмотр в MockMode попадал в протокол вместо открытия окна. Для явного действия «Предпросмотр» теперь используется принудительный показ собственного окна; итоговый GUI-прогон проходит. Первый перенос TXT-стенда после удаления памяток выявил оставшиеся старые тестовые команды. Они заменены текущими сигналами/УК; итоговый прогон выше проходит. Проверки не отключались.

## Что не проверено

Настоящий Amazing/GTA, адреса его диалога и фактическая маршрутизация GPS, эксклюзивный fullscreen и кадры OBS здесь не проверены. Транспорт, флаг чата и наблюдение игрового диалога в стенде — явные подмены. Фиксация списка/поля в Win32-стенде не подтверждает совместимость смещений конкретного клиента. При несовместимой структуре операция завершится по таймауту с этапом отказа.

Старые CLI/Auto ID/печать/законы отчёты в `reports` исторические; они не выдаются за отдельный повторный прогон этой сборки. Последующие шаги Windows CI повторно проверяют ввод, GUI, обновление laws и меню. [Клиентский чек-лист](CLIENT_CHECKLIST_RU.md).

ФЗ о ФСБ в предоставленной базе не содержит статей 24–31; карты остаются необязательными локальными ресурсами. Новых редакций законов в этой задаче не добавлялось.
