Открытие памятки теперь закрывает поиск, который иначе перехватывал PgUp/PgDn. Добавлены два настоящих GUI-условия: открытие результата поиска и уничтожение его окна при переходе к памятке. После исправления получения HWND в тесте отдельно повторён desktop smoke: 113/0. Остальные CLI-результаты относятся к побайтно идентичным исходникам приложения; различался только исправленный тест. Отпечатки и происхождение прогонов записаны в `summary.json`.

Первый прогон с новой базой выявил устаревшие ожидаемые номера статей в тестах. Проверки обновлены по фактическому тексту: ФЗОП 20/22, КоАП 17.4, ФЗ о территориях 12 ч. 2. Статьи 9.2/17.5 из прежней базы не добавлялись ради зелёного результата. Временные клавиши новых тестов также отделены от тестового бинда представления. Первый Windows CI подтвердил запуск EXE и GUI, но выявил зависимость новых Python-стендов от системной кодировки при чтении UTF-8 JSON. Чтение JSON сделано явным UTF-8; причина отдельно воспроизведена декодированием CP1252 и проверена при отключённом Python UTF-8 mode. Окончательный Windows-результат фиксируется ниже после повторного прогона.

## Что не подтверждено этими проверками

Реальный Amazing Online/GTA, адреса конкретного клиента, память/ABI при отправке в игру, эксклюзивный fullscreen и кадры OBS в облаке не проверены. Mock-транспорт и тестовый foreground не заменяют клиент. Общий Capture-механизм применяется к новым окнам, но его наличие не доказывает исключение из реальной записи.

ФЗ о ФСБ в приложенном источнике неполон: нет статей 24–31. Новых иллюстраций нет; 17 локальных карт отсутствуют и считаются необязательными, старые локальные изображения помечаются архивными. [Клиентский чек-лист](CLIENT_CHECKLIST_RU.md).

Исторические отчёты исправлений ввода/GPS/Auto ID предыдущих этапов сохранены в `reports`; они не являются отдельным повторным прогоном этой сборки. Windows CI повторно запускает стенды ввода и меню после публикации.
