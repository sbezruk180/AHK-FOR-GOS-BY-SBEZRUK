# Удобство AHK — 6 ноября 2026

Резервная версия до изменений: [backup-ahk-2026-11-06](https://github.com/sbezruk180/AHK-FOR-GOS-BY-SBEZRUK/tree/backup-ahk-2026-11-06), commit `182db91`. Она содержит прежние исходники и все три готовых EXE в `release`. Для отката распакуйте её в отдельную папку. Пользовательские INI этим обновлением не заменяются; перед ручной заменой своей установки сохраните её INI и папки пользовательских данных.

## Изменения

- Постоянная кнопка «Инструменты». Палитра, карточка дела, результаты действий, учебная площадка, GPS и конструктор доступны вверху страницы.
- Убрана ошибочная подсказка с фиксированным чужим ником. Описание сохранения честно сообщает о сохранении при закрытии настроек.
- Более понятные русские подписи настроек, без изменения ключей INI.
- Палитра обновляет результаты до обработки быстрого Tab и стрелок. Enter запускает выделенную строку. При изменении запроса прежний выбор сбрасывается. Пробел сохраняет прежний запуск точного TXT-бинда.
- В конструкторе русские названия блоков; у таймера отдельные секунды и название. Неверные числа отклоняются до добавления.
- Исправление повреждённого блока больше не превращает его в отправку текста. Заметки не получают лишний знак комментария. Номер строки не выглядит редактируемым.

Сохранён AutoHotkey v1.1 ANSI x86, формат сценариев и профилей. Адреса памяти, игровые задержки и семантика отправки не менялись.

## Проверка

Проверка проводится через `.github/workflows/usability.yml`: сборка EXE и установщика из текущих исходников; три прогона AHK и три EXE на Windows; отдельные тесты установки/удаления; снимки GUI. Скачать новый бинарник из ветки результатов можно только после успешного прохождения всех проверок. Файл `result.json` содержит итог конкретного запуска.

Реальные Amazing, эксклюзивный DirectX fullscreen и полученная запись OBS требуют проверки на компьютере с игрой. Нативные тесты используют собственные окна и фикстуры, а не сервер.
