# Анализ и выбранная реализация

Базовая версия: `e4cd4cb6ebf6c958975c8977663ff6b7ff4b2bbc`, 16 октября 2026.

## Исходный проект

Основной файл содержал 23 347 строк, 1 043 определения функций и 191 именованную метку; 451 функция helper одновременно находилась в отдельном справочном файле. Вместе с реально подключёнными модулями исполняемый граф содержит 1 284 исходные функции. Отдельный helper ранее не подключался: это был генерируемый дубль. Теперь он стал единственной канонической реализацией и включается один раз. Полный перечень функций, прежние расположения и SHA-256 тел записаны в `migration_inventory.json`.

Все корневые AHK-модули, статические включения, проверки и LAW-файлы прочитаны сборочным анализатором. Проверены функции процесса/памяти, объявления и инициализация глобальных состояний, callback/hook API, реестр биндов, таймеры, пути файлов, диагностические режимы и завершение. Миграционный контроль требует сохранения каждого исходного определения и каждого старого обработчика; одно совпадение имён не объявляется функциональным тестированием.

Низкоуровневый контракт: 32-битный `gta_sa.exe`, PE32 `azmp.dll`, 32-битные адреса, собственные смещения клиента, ANSI CP1251-аргументы удалённых функций. `common.ahk` владеет HANDLE, выделениями и удалёнными потоками. Неопределённый результат отправки после запуска потока запрещает повтор. `UDF.ahk` проверяет PlayerInfo/CPed, GTA-пул, смену процесса и привязку ID. Эти модули не переписаны и не заменены имитациями.

Ввод использует динамические Hotkey/Hotstring AHK, условия контекста, WinAPI keyboard hook и InputHook, VK/scancode-печать, отдельные задержки символов и последовательностей, Clipboard с восстановлением, очередь, поколения отмены и взаимное исключение ручного ввода. Менять только язык этих частей без повторной реализации AHK-семантики небезопасно для совместимости.

Интерфейс использует native Windows GUI, HWND, OnMessage, владельческий рендер кнопок/палитру, пассивные оверлеи, регион окна, DPI/прокрутку и исключение захвата через WDA_EXCLUDEFROMCAPTURE. Настройки включают 13 страниц; профили/темы/конструктор функций используют INI, атомарные staging-файлы и миграцию схемы 14. LAW: 20 CP1251-документов, GDI-пагинация, индекс, словоформы, опечатки и фильтры. Также сохранены chatlog, доказательства/скриншоты, автодоклады, GPS, транспортные/контекстные мастера, документы и все каталоговые действия.

## Сравнение технологий

| Вариант | Сильная сторона | Цена сохранения совместимости | Решение |
|---|---|---|---|
| C++/Win32 x86, статический CRT | Минимальная нативная база, точный ABI, один EXE | Новая реализация hotstring/hook/InputHook, GUI, INI, регулярных выражений и всех сценариев; много новой небезопасной WinAPI-логики | Хороший будущий низкоуровневый слой; полный перенос сейчас увеличивает риск потерь |
| Rust/i686 Windows | Контроль ресурсов, безопасность основной модели памяти | FFI остаётся unsafe; нужно заново реализовать AHK-семантику и GUI; нет автоматического переноса этих 1 284 функций | Подходит для новых изолированных подсистем после клиентских тестов |
| C#/.NET self-contained x86 | Удобные модели/интерфейс, хорошие инструменты | JIT/runtime и размер публикации; P/Invoke; WPF/WinForms не повторяют текущие GUI и hooks автоматически; NativeAOT не даёт готового решения этого AHK ABI | Возможен новый UI, но не минимальный путь к полной совместимости |
| Qt/C++ | Современная графика и развитие UI | Статическая сборка/лицензии, новая UI-реализация, семантика ввода и сценарии всё равно переносятся вручную | Избыточен для первого этапа |
| Python/PyInstaller | Быстрая разработка | Большая среда, упаковка/распаковка, дополнительный слой для hooks и ANSI x86, перенос сценариев/GUI | Не отвечает приоритету минимальных ресурсов и минимального риска |
| Официальный встроенный AHK 1.1 ANSI x86 + модульный host | Сохраняет действующий ABI, обработчики, интерфейс и все сценарии; один небольшой PE32 | Наследует ограничения AHK v1/ANSI и глобальную модель состояния | **Выбран для этой реализации** |

Это самостоятельное приложение со встроенным официальным runtime, а не загрузчик, распаковывающий и запускающий внешние скрипты. Полный нативный перенос не был выдан за готовый результат. Для этого объёма исходников сохранение языка на первом этапе обосновано главным приоритетом — совместимостью.

## Изменения архитектуры

Главный AHK стал точкой входа. `app/state.ahk` централизует сохранённое состояние; `app/bootstrap.ahk` выполняет инициализацию один раз; `app/events.ahk` содержит адаптеры UI/таймеров/биндов. Определения разнесены по подсистемам. Порядок выполняемых начальных действий и обработчиков сохранён. Подробные границы перечислены в `ARCHITECTURE_RU.md`.

Добавлен host путей/ресурсов, встроенная база LAW, совместимая диагностика исходников внутри EXE, перенос старых настроек без перезаписи назначения, общий mutex исходной/EXE-версии, завершение собственных диагностических процессов по HANDLE. `#SingleInstance Force` заменён на mutex: диагностический запуск того же EXE больше не должен принудительно завершать основную программу. При неудачном сохранении исправлен сброс флага выхода.

При GUI-проверке исправлено обновление ещё не созданного списка биндов: теперь оно не создаёт скрытое окно и не обращается к несуществующим контролам. Игровые алгоритмы и скорости последовательностей ради упаковки не изменены.

## Обнаруженные зависимости

| Зависимость | Сборка | Запуск EXE |
|---|---|---|
| 9 исходных корневых AHK и `app/*.ahk` | Обязательны, включаются в проверяемый граф | Встроены; внешние скрипты не нужны |
| Подключаемые `tests/*.ahk` | Обязательны для встроенных диагностических режимов | Встроены, не исполняются при обычном запуске |
| `laws/*.txt`, 20 документов | Обязательны | Встроены; пользовательские файлы могут переопределить документ |
| Официальная база `ANSI 32-bit.bin` 1.1.37.02 | Обязательна; архив и файлы проверяются по SHA-256 | Runtime уже внутри EXE |
| Python 3.10+ | Только сборка/проверка исходников | Не требуется |
| `profiles[_updated].ini`, `themes.ini`, `custom_functions.ini` | Не нужны для сборки | Изменяемые данные; прежний формат сохраняется |
| Картинки `assets/law_maps/*` | Не предоставлены; README исходников это подтверждает | Не обязательны для запуска; локальные карты требуют этих изображений, форумные действия сохранены |
| Собственные звуки/фон, chatlog | Пользовательские данные | Не вшиваются как чужие файлы; сохранены прежние настройки/пути |
| GTA/Amazing, `azmp.dll` | Не нужны для сборки | Нужны для игровых функций; клиент не включается в дистрибутив |

Исходный AHK v1 ANSI предполагает системную ANSI-кодовую страницу Windows 1251 для полноценного русского текста. Упаковка не устраняет это ограничение. Режим `--runtime-info` явно показывает GetACP, архитектуру и статус встроенных ресурсов.
