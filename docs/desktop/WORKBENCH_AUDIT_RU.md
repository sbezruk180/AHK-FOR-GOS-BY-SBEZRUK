низкоуровневые адреса игры для этих изменений не переписывались.

## Подтверждённые исправления

- В GUI карточки переменные контролов сделаны глобальными: локальные `vVariable`
  внутри функции приводили к ошибке AHK v1 при открытии окна.
- Палитра сохраняет пользовательские функции старого формата без поля `Enabled`;
  локальные служебные алиасы не подменяют настроенные TXT пользователя.
- Пустой запрос не запускает первый результат; быстрое Enter учитывает последний
  введённый текст, даже если таймер подсказок ещё не обновился.
- GPS сохраняет несохранённые значения после пробного запуска; старый отложенный
  callback не может запустить новый запрос или действие другого профиля.
- Журнал сохраняет выполненный шаг после ошибки последующего обработчика,
  запрещает повтор неопределённого вызова и показывает итог родительского действия.
  Длинный сценарий не теряет свою запись из-за завершённых дочерних отправок.
- Приватный TXT-диспетчер не оставляет отложенную метку действия после завершения
  обучения. Очередь и длительные операции продолжают проверять эпоху выполнения.
- Обучение изолировано даже при изменённом флаге MockMode: транспорт и клавиши
  остаются локальными, память/реальные скриншоты и фоновые чтения блокируются.
  Сохранение настроек сохраняет учебный режим; исходный выбор возвращается при выходе.
- Блокировка временного файла карточки не оставляет писатель занятым навсегда;
  последующая запись восстанавливается, сохранённая версия не повреждается.
- Повторные экспорты в одну секунду получают разные имена и не затирают прежний файл.
- Диагностика различает каталог исходников и каталог пользовательских данных,
  проверяет действительный путь законов, учитывает старые INI версии 1.0/схемы 14
  и не принимает отсутствующий ключ `ERROR` за конфликт биндов.
- Удаление с сохранением данных сохраняет карточки; полное удаление убирает также
  папку карточек переносимой установки.

Это исправления существовавших проблем и обнаруженных ошибок при интеграции новых
модулей. Они не обозначают, что все перечисленные дефекты присутствовали в старом
публичном релизе до начала этой работы.

## Результаты

Проверяемая сборка: `81e1c167b0f77b14ea59a09590ee906b3564cfb1`.
[Windows, AHK и EXE: три повторения каждого формата](https://github.com/sbezruk180/AHK-FOR-GOS-BY-SBEZRUK/actions/runs/40407226554).
Машиночитаемые результаты: [native summary](reports/workbench-native-20261026.json).

В каждом из шести заданий выполнено 27 сценариев: исходный и инструментированный
код, запуск/второй экземпляр/выход, CLI-проверки, окна и отдельные Win32-фикстуры.
Итого 162 сценария; ошибок и оставшихся процессов тестовой установки нет.
Предусмотренные проверки только для EXE отмечены отдельно для формата AHK.

Проверка сохранения исходной функциональности: все 1284 исходные функции и 191
метка событий сохранены по одному экземпляру. 1108 тел исходных функций не
изменены, 176 адаптированы. Это проверка сохранения кода и связей, а не доказательство
выполнения каждой игровой функции на сервере. Полный краткий индекс с действиями
и строками: [FUNCTIONS_RU.txt](FUNCTIONS_RU.txt).

Проверены CP1251/CRLF без BOM, единственное подключение helper, 57 встроенных
модулей, 20 корпусов законов, соответствие исходников EXE и установщику. Профиль
первого запуска сохранён, существующие пользовательские INI не заменяются.

На англоязычном Windows runner тестовые копии A32 получают только manifest
`activeCodePage=ru-RU`: исполняемый код и полезная нагрузка остаются исходными.
Проверки устанавливаемых setup/uninstaller выполняются их опубликованными бинарниками.

## Границы проверки

Реальный Amazing-клиент/сервер, его текущие адреса памяти, поведение античита,
эксклюзивный полноэкранный DirectX-режим и фактическая видеозапись OBS здесь не
проверялись. Для ввода использовались настоящие Win32-окна и клавиатурные события;
для низкоуровневого API — собственный тестовый процесс и PE32-области памяти.
Наличие игровых предикатов/ответов в фикстурах обозначено явно.

Отсутствие сбоев в этих проверках не означает доказанного отсутствия ошибок
во всех конфигурациях Windows и игрового клиента.
