# Технические ограничения

1. Релиз — встроенный официальный AHK 1.1.37.02 ANSI x86 с модульным приложением. Полного переписывания на C++/Rust/C# нет. AHK v1 и его глобальная модель состояния остаются ограничением развития; границы подсистем выделены для дальнейшей замены.
2. Игра и `azmp.dll` не входят в дистрибутив. Подтверждённые пользователем ранее методы сохраняют код, но актуальные адреса, совместимость конкретного клиента/античита и реальные игровые действия в облаке не подтверждены. Непустой эталон SHA по-прежнему проверяется строго.
3. Русский ANSI предполагает системную кодовую страницу Windows 1251, как исходный проект. Англоязычная/UTF-8 ANSI-конфигурация не объявляется совместимой. Перевод на Unicode требует отдельной проверки всех низкоуровневых контрактов.
4. Изображения для 11 групп локальных карт не предоставлены и не были частью публичных исходников. Не созданы вымышленные карты. Каталог/форумные ссылки/обработка отсутствующих файлов сохранены; диагностика выводит явное предупреждение. Пользовательские картинки можно добавить в папку данных.
5. Наличие WDA_EXCLUDEFROMCAPTURE проверяется кодом, но отсутствие кадров в реальном OBS, конкретные методы захвата, DPI/несколько мониторов/полноэкранный клиент проверяются на Windows отдельно.
6. Для изменяемых настроек, логов, резервных копий и пользовательских ресурсов остаются внешние файлы. Внешних обязательных исполняемых компонентов/скриптов нет. По запросу диагностики возможен короткий запуск этого же EXE в CLI-режиме; основной процесс управляет его HANDLE и завершением.
7. Облачный Linux/Wine не заменяет Windows ANSI x86. Раздельно указаны упаковка релизного PE32, проверки тестового Unicode x64 EXE, проверки реальных Windows UI API под Wine и невыполненные игровые проверки. Готовность клиента не выводится из одной успешной компиляции.
8. Локальные тексты законов — сохранённая редакция исходной базы, не автоматически актуальное законодательство сервера.
