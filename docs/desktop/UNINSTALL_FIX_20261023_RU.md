# Исправление удаления 1.1 — 23.10.2026

Исправлены реальные пробелы удаления. Игровой EXE и AHK-код не изменялись.

## Причины

- Манифест содержал исходные имена: переименованный основной EXE/AHK пропускался.
  Переносимая копия без манифеста тоже искалась под фиксированным именем.
- Старые зависимости, отсутствующие в современной сборке, не узнавались.
- Общий поиск показывал только файлы и не предлагал удалить всю папку с ресурсами.
- Любой reparse-атрибут считался ссылкой: это исключало cloud-placeholder OneDrive.
- Ярлыки удалялись только под заранее заданными именами.
- Внешние профили сохранялись правильно, но после удаления оставалась пустая
  папка с манифестом; отчёт не показывал число фактически удалённых объектов.

## Изменения

- Распознавание EXE по данным продукта с учётом языковых таблиц; основного AHK —
  по хешу/структуре включений; переименованных модулей — по известным хешам.
- Каталог 60 файлов указанного архива `6b1a595` и шести LF-вариантов CMD/PS1
  из Git. ZIP-экспорт содержит CRLF, поэтому его хеши отличаются от Git blobs.
- В режиме 1 отдельные строки `[ПАПКА ЦЕЛИКОМ]`: удаляется вся выбранная папка,
  включая не-AHK файлы и вложенные каталоги. Пересекающиеся выбранные файлы
  не удаляются повторно. Все строки по умолчанию сняты.
- Перед удалением папки сверяются полный список, файловые идентификаторы,
  размеры и время изменения. Если после поиска добавился/изменился файл,
  папка остаётся на месте, причина появляется в отчёте.
- Рабочий стол, документы, загрузки, профиль, системные корни и их предки
  не предлагаются к удалению целиком. Junction/symlink и неизвестные reparse-типы
  не обходятся. Cloud-теги OneDrive обрабатываются отдельно.
- Ярлыки на рабочем столе и в пользовательском меню Пуск узнаются по пути цели
  или AHK-пути в аргументах глобального интерпретатора, независимо от названия.
- Режим 3 удаляет опустевшую папку установки; внешние профили остаются.
  Если рядом лежат переносимые INI/посторонние файлы, они и небольшой манифест
  остаются для переустановки. Запущенный переименованный унинсталлер тоже удаляется.
- В отчёте есть точный корень, количество файлов/папок и сообщения Windows.
  Пустой повторный запуск не выдаёт сообщение об успешном удалении.

## Как удалить старую папку из GitHub ZIP

Для одной копии в режимах 2/3 выберите её папку, например
`%USERPROFILE%\OneDrive\Рабочий стол\AHK-FOR-GOS-BY-SBEZRUK-6b1a595…`.
Запускайте отдельный унинсталлер из другой папки, например из «Загрузок».
Для удаления всех копий используйте режим 1: после поиска отметьте нужные строки
`[ПАПКА ЦЕЛИКОМ]`, затем введите `УДАЛИТЬ` и отметьте подтверждение.
**Вместе с выбранной папкой удаляется всё её содержимое.**
Недоступные объекты остаются с ошибкой; программа не выдаёт это за полное удаление.
