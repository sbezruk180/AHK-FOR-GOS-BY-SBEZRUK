# Фракционная печать и переменный темп — 20.10.2026

## Два маршрута отправки

- **Фракция: остальное вставка**: команды из редактируемого списка фракции отправляются через физическую печать, другие строки — существующим механизмом вставки.
- **Фракция: остальное память**: те же фракционные команды печатаются; другие строки идут через существующий метод памяти. При недоступной памяти этот режим сообщает отказ и не меняет метод на вставку. Начатая/неопределённая операция памяти возвращает прежний код неопределённости, без вставки или повторного вызова транспорта.

Старый INI-режим `FactionTyping` и прежняя подпись «Печать фракции» означают вариант вставки. Новый режим хранится как `FactionTypingMemory`. Выбор маршрута использует локальную переменную, не переписывает глобальную настройку во время отправки. `Auto`, `Memory`, `Keyboard`, `FastTyping` сохраняются. Сопоставление команд использует границу токена: `/cuffing` не считается `/cuff`.

## Случайный диапазон CPS

На странице «Чат и безопасность», в блоке печати выберите «Случайный темп (симв/с)» и границы «От»/«До». Поддерживаются целые 1–1000 целевых символов/сек.; перепутанные границы меняются местами, некорректные значения заменяются допустимыми. Одинаковые границы дают постоянный целевой темп.

Для каждого символа выбирается случайная целая скорость в диапазоне. В целевой интервал от начала символа до следующего входит время нажатия и переключения раскладки. Поверх уже затраченного времени полный интервал повторно не добавляется. Границы фиксируются на время одной строки, поэтому изменение настроек не меняет диапазон посередине набора.

Удержание клавиши 10 мс сохранено. Переключение раскладок, вызовы Windows, проверки контекста и игра дополнительно ограничивают реальную пропускную способность. Целевые 150 или 1000 симв/с не являются обещанием такого фактического темпа. Диапазон по умолчанию — 20–40; после обновления остаётся прежний режим постоянного интервала, пока пользователь явно не включит случайный темп.

Пауза выполняется короткими прерываемыми отрезками. Отмена, смена окна, поколения операции или закрытие чата прекращают печать. Настройки WAIT/таймеров/очереди/паузы действия не изменяются. Явная задержка 0 для RP вокруг действия имеет приоритет над случайным темпом.

## Конфигурация

Новые необязательные ключи секции UI: `ChatTypingSpeedMode` (`Fixed`/`RandomCPS`), `ChatTypingMinCPS`, `ChatTypingMaxCPS`. Старый `ChatTypingDelayMs` остаётся для постоянного интервала. Отсутствие новых ключей не меняет прежний способ печати. Используются существующие чтение и атомарная запись INI; перенастройка профилей/биндов не нужна.

## Проверки

- Производственный маршрутизатор проверяется отдельным стендом с явно считающими подменами трёх транспортов: фракция/обычный текст, вставка/память, неизменность настройки режима, недоступная память, обнаружение начатой операции, неопределённый результат, точная граница команды.
- Стенд с реальными клавишами проверяет точный текст, 10 символов при 5 симв/с и быструю отмену паузы при 1 симв/с. Проверяется освобождение ввода.
- Регрессии проверяют допустимость диапазона, учёт времени нажатия, приоритет RP, старую подпись режима и реальную запись/чтение INI.
- Desktop smoke проверяет реальные элементы новых настроек и их запись/чтение. Тестовая копия INI сохраняет исходную кодировку, включая UTF-16 на английском Windows runner.
