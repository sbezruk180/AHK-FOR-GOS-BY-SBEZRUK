# Нативный установщик и удаление — 22.10.2026

Готовы `AHK_FOR_GOS_Setup.exe` и отдельный `AHK_FOR_GOS_Uninstall.exe`.
Это C++17/Win32/GDI+, GUI-приложения x64 со статической библиотекой выполнения.
Импортируются только системные DLL Windows; CMD, PowerShell, браузерный движок,
.NET и Python для работы не нужны. Установка не скачивает компоненты.

[Инструкция и устройство проекта](../../installer/README_RU.md),
[главный экран](installer-previews/setup-home.png),
[настройки](installer-previews/setup-options.png),
[удаление](installer-previews/uninstall-home.png).

## Что реализовано

- Выбор EXE или исходного AHK с официальным локальным ANSI x86 runtime.
- Все 46 включаемых AHK-модулей, 20 законов и доступные ресурсы; без потери
  зависимостей, включая используемые проектом `tests/*.ahk`.
- Общая папка профилей, корректные параметры ярлыков, регистрация в списке
  приложений Windows, выбор папки и необязательных ярлыков.
- Тёмный интерфейс, фиолетовый акцент, плавное наведение, переходы страниц,
  клавиатурная навигация, DPI и работа в отдельном нативном окне.
- Необязательная инструкция; уведомление об ответственности на главной странице.
- Проверка 76 payload-файлов по SHA-256, подготовка перед заменой, откат при
  обрабатываемом сбое и сохранение изменённых файлов прежней установки.
- Три режима удаления: все найденные AHK и распознанные EXE этого проекта;
  только проект с данными; проект с сохранением профилей.
- В широком режиме: фоновый поиск, отмена, список точных путей, ручной выбор,
  ввод `УДАЛИТЬ`, отдельная отметка о риске удаления чужих скриптов. Проверка,
  что файл не изменился после сканирования. Ссылки и недоступные объекты пропускаются.
- Поддержка старых копий без манифеста при распознаваемом EXE или точном хеше
  основного AHK: удаляются подтверждённые файлы; неизвестные сохраняются.
- Ассоциации других AHK и чужие EXE не изменяются. Исполняемый файл самого AHK
  встроен без изменений; игровые функции в этой задаче не переписывались.

## Границы проверки

- Сканирование всего компьютера и удаление настоящих пользовательских файлов
  не выполнялись. Сканер проверен на временном дереве с AHK, переименованным EXE
  этого проекта и чужим EXE. Ничего не выбирается автоматически.
- Внешняя корзина: проверены пустой выбор и отказ при изменении файла;
  успешный цикл отправки/восстановления чужих пользовательских файлов не заявляется.
- Регистрировать ARP и создавать ярлыки на настоящем пользовательском рабочем
  столе автотесты не стали; используются реальные WinAPI/COM, возможные ошибки
  регистрации показываются в отчёте операции.
- Снятие собственного работающего Uninstall.exe выполняет временный нативный
  помощник; полный интерактивный цикл самоудаления на пользовательской машине
  отдельно не подтверждён. Варианты файлового удаления проверены в Temp.
- Игра, сервер, OBS, политики антивируса/организации и все варианты DPI не проверялись.
  Установщик не меняет системную локаль; для старого ANSI-приложения остаются
  требования совместимости CP1251. Цифровой подписи сертификатом нет.

Для повторения: `tools/verify_installer.py` проверяет упаковку;
`Setup.exe --self-test <отчёт>` — файловые сценарии в Temp;
`Setup.exe --ui-test <отчёт>` / `Uninstall.exe --ui-test <отчёт>` — демонстрационные
GUI-сценарии без установки/удаления пользовательских данных.
