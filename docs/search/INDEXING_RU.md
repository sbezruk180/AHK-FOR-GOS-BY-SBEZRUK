# Индексация AHK FOR GOS

Публичная страница проекта: https://github.com/sbezruk180/AHK-FOR-GOS-BY-SBEZRUK

Запрос для проверки: `ahk for gos`. [Протокол Chromium и снимки](latest/README.md).

## Что опубликовано

- В README основной ветки название **AHK FOR GOS** стоит в начале заголовка; добавлено описание на русском и английском, официальные загрузки и ссылки на исходники.
- В ветке `gh-pages` подготовлены страница с названием проекта, описанием и SoftwareApplication JSON-LD, `robots.txt` и `sitemap.xml`.
- Проверка настоящих поисковых страниц запускается workflow `search-visibility.yml`. Капча, сетевой сбой или невидимые результаты не считаются отсутствием проекта в индексе.

## Почему сайт пока не опубликован

GitHub API отказал токену GitHub Actions во включении Pages: `Resource not accessible by integration`. Это ограничение прав GitHub, а не ошибка сборки. Наличие ветки `gh-pages` само по себе не делает сайт доступным.

Владельцу репозитория нужно открыть:
https://github.com/sbezruk180/AHK-FOR-GOS-BY-SBEZRUK/settings/pages

Выбрать **Deploy from a branch → gh-pages → / (root) → Save**. После успешной публикации ожидаемый адрес:
https://sbezruk180.github.io/AHK-FOR-GOS-BY-SBEZRUK/

До получения HTTP 200 этот адрес нельзя объявлять работающим сайтом.

После публикации владелец может добавить URL-префикс сайта в Google Search Console, Яндекс Вебмастер и Bing Webmaster Tools, подтвердить владение предоставленным ими файлом или meta-тегом и отправить `sitemap.xml`/запрос проверки URL. Доступа к аккаунтам владельца и кодов подтверждения у приложения нет. Эти действия не гарантируют индексацию или определённое место в выдаче.

Публичные упоминания и ссылки от реальных пользователей помогают обнаружению проекта. Накрутка звёзд, фиктивные отзывы и массовый спам не используются.
