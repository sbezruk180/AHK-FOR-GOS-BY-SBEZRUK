# Индексация AHK FOR GOS

Публичная страница проекта: https://github.com/sbezruk180/AHK-FOR-GOS-BY-SBEZRUK

Запросы для проверки: `ahk for gos`, `ахк для гос`, `ахк для амазинга`. [Протокол первого запроса и снимки](latest/README.md); после публикации в main workflow сохраняет также результаты остальных двух запросов в соседние папки.

## Что опубликовано

- В README основной ветки название **AHK FOR GOS** стоит в начале заголовка; добавлено описание на русском и английском, официальные загрузки, полный актуальный проект и [каталог действий](../../FEATURES.md).
- В ветке `gh-pages` подготовлены страница с названием проекта, описанием и SoftwareApplication JSON-LD, `robots.txt` и `sitemap.xml`.
- Проверка настоящих поисковых страниц запускается workflow `search-visibility.yml`. Капча, сетевой сбой или невидимые результаты не считаются отсутствием проекта в индексе.

## Сайт опубликован

GitHub Pages включён на ветке `gh-pages`, путь `/`. Проверка GitHub Actions подтвердила HTTP 200:
https://sbezruk180.github.io/AHK-FOR-GOS-BY-SBEZRUK/

[Текущий статус Pages](pages-status.json). Ранее служебному токену не хватало прав на включение сайта; это ограничение больше не блокирует публикацию.

На сайте также размещается [каталог 93 действий](https://sbezruk180.github.io/AHK-FOR-GOS-BY-SBEZRUK/features.html). Проверяемые актуальные URL перечислены в sitemap.

Workflow `indexnow.yml` проверяет публичный файл владения и обе страницы, затем отправляет только эти URL в IndexNow. [Фактический ответ](indexnow-submission.json) появляется после выполнения workflow. HTTP 200/202 означает принятие заявки, а не индексацию и не повышение позиции. IndexNow используется поддерживающими его поисковиками; отправка через него не является заявкой в Google.

Для Google и дополнительной диагностики владелец может добавить URL-префикс сайта в Google Search Console, Яндекс Вебмастер и Bing Webmaster Tools, подтвердить владение предоставленным ими файлом или meta-тегом и отправить `sitemap.xml`/запрос проверки URL. Доступа к аккаунтам владельца и кодов подтверждения у приложения нет. Эти действия не гарантируют индексацию или определённое место в выдаче.

Публичные упоминания и ссылки от реальных пользователей помогают обнаружению проекта. Накрутка звёзд, фиктивные отзывы и массовый спам не используются.
