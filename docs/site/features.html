Функции AHK FOR GOS для Amazing Online

Открытый АХК для госструктур Amazing Online от sbezruk180. Ниже перечислены все 93 действия встроенного каталога с исходными назначениями и ссылками на реальный код.

Назначения вашего профиля могут отличаться. Обозначения AutoHotkey: ! — Alt, ^ — Ctrl, + — Shift, # — Win. Прочерк означает отсутствие назначения по умолчанию.
