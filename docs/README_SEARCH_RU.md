# AHK FOR GOS — AHK для Amazing Online 1.1

**AHK FOR GOS BY SBEZRUK** — бесплатный помощник для госструктур Amazing Online (GTA San Andreas Multiplayer): горячие клавиши, текстовые бинды, RP-сценарии, Auto ID и поиск по законодательству.

**AHK FOR GOS** is an open-source AutoHotkey assistant for government factions in Amazing Online (GTA San Andreas Multiplayer), maintained by **sbezruk180**. Download the official Windows installer, standalone EXE or AHK source package below.

## Возможности

Настраиваемые бинды и TXT-команды, конструктор действий, профили, Auto ID при наведении с F1/F2, режимы отправки чата, GPS, HUD и служебные окна. Встроены 20 документов законодательства и поиск статей. Меню открывается F10; интерфейс TXT-команд — Alt+T. Конкретные бинды можно изменить.

Установка доступна как AHK или EXE. Унинсталлер необязателен. Полное удаление работает без корзины: перед подтверждением проверьте выбранные файлы, ZIP и папки.

## Совместимость и помощь

Windows 10/11 x64 для установщика; приложение использует AutoHotkey 1.1 ANSI x86 и совместимую русскую кодовую страницу CP1251. Работа памяти, Auto ID и захвата OBS зависит от версии клиента и Windows. Отсутствие блокировок аккаунта не гарантируется; проверяйте правила сервера.
