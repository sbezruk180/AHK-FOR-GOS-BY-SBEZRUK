## Исправления по техническому аудиту

- Исправления F01–F30: очередь и отмена действий, память/HANDLE, chatlog, сохранение INI, ограничение собственных логов, нативный SHA-256, согласование helper.
- Исключение собственных окон из поддерживаемого захвата OBS через Windows API.
- Поиск: словоформы и ограниченные опечатки, точные фразы, исключения, приоритет заголовков и обновление индекса по содержимому.
- Карточки профиля/патруля/поста, читаемость цветов, кнопки и прокрутка настроек на небольших экранах.
- Новый `--audit-selftest`, Windows runner и проверка упаковки.
- См. `AUDIT_FIXES_RU.md` для ограничений интеграционной проверки и изменений поведения.

# Changelog

## Unreleased

- Добавлены режимы отправки `FastTyping` («Печать всего») и `FactionTyping` («Печать фракции»). Интервал между символами — 1–100 мс, по умолчанию 5 мс; список команд редактируется и сопоставляется с первым токеном целиком. Начальный список включает `/frac`, `/cuff`, `/deject`, `/mdc`, `/chase` и связанные команды.
- Новый ручной режим «Перехват цифр» выбран по умолчанию: существующий Alt+1 запускает ввод, повтор бинда или Enter применяет ID, Backspace редактирует, Esc отменяет. Таймер по умолчанию — 3 секунды от запуска, без продления при наборе. Плашка не забирает фокус, пропускает клики и использует общий переключатель скрытия в OBS.
- На время ручного ввода приостанавливается Auto ID; потеря фокуса, смена профиля и отмена автоматизации отменяют ввод. Печать и перехват исключают друг друга; частично напечатанное сообщение не повторяется автоматически.
- Исправлено сохранение переключателя скрытия окон из OBS.
- Добавлены обязательные модули `chat_typing.ahk`, `id_capture.ahk` и подключаемые проверки `tests/chat_typing_regression.ahk`, `tests/id_capture_regression.ahk`. Код сохраняет CP1251/CRLF и целевой AutoHotkey 1.1.37.02 ANSI x86. Проверки U64/Wine не заменяют проверку Windows ANSI x86 и игры.
- Восстановлен быстрый Auto ID: точная цель подтверждается первым наблюдением с повторной проверкой PED; чтение не требует необязательного эталонного хеша DLL.
- Исправлены отступы профиля и настроек, наследование жирного шрифта и масштабирование DPI; длинные страницы и тексты получают прокрутку.
- Исправлены повторные попытки исключения из захвата OBS, проверка фактического флага каждого окна и отображение частичных отказов.
- Установщик версии из ветки исправлений скачивает эту ветку вместо устаревшего main.
- Добавлен инспектор геометрии открытого GUI `tools/audit_gui.ahk` и регрессии Auto ID/OBS.

- В репозиторий добавлена локальная база из 20 LAW-документов.
- README дополнен проверенным списком основных функций проекта.
- Удалена устаревшая инструкция по ручному добавлению LAW-файлов.
